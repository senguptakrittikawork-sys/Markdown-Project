# Introduction

Oracle Database Patch Set Updates (PSUs) are quarterly cumulative updates designed to address critical security vulnerabilities, performance issues, and stability improvements. Unlike major upgrades, PSUs focus on enhancing existing functionality without introducing new features, making them simpler to apply with minimal disruption. 

# Procedure

Perform the following steps: 

•	Confirm the Database (DB) version is Oracle 19c.

•	Ensure root privileges is available for the Admin user. 

•	Take server snapshot / backup before starting the patching activity.

•	Identify the patch script location and confirm access to the required patch package.

•	Raise the Change Request CRQ and obtain the necessary approvals

•	Notify the Pharmacy Application Team / RxSupport team RxSupport@meijer.com (stakeholders) of the upcoming activity (PSU Patching Implementation Plan)

•	Ensure that the ORACLE_HOME, ORACLE_SID, and PATH point to your target
 server configurations
